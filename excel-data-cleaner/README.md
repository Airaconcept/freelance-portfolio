# Excel Data Cleaner - merge messy spreadsheets into one report

Merges several Excel/CSV files that were exported from different systems - different column names, mixed date formats, duplicates, blank rows - into **one clean table**, then adds a **pivot summary** and **native Excel charts**. One command, one workbook.

## What problem it solves

Monthly reporting often starts with three or four exports that never line up: one branch calls it `Qty`, another `quantity`, the webshop `Units`; one file has `03/04/2026` meaning 3 April, another meaning 4 March; some orders appear twice. This tool:

- **maps column names** onto one schema (`Order ID` / `order_no` / `OrderID` -> `order_id`, ...), ignoring case, spaces and punctuation; extra columns are ignored
- **parses dates in any common format**: real Excel dates, Excel serial numbers, ISO `2026-04-03`, `03/04/2026`, `03.04.2026`, `3 Apr 2026`. For slash dates it decides **per file** whether the file is day-first or month-first by looking at all its values (any first part > 12 means day-first)
- **cleans values**: trims spaces, unifies spelling (`ACME CORP`, `acme corp ` -> `Acme Corp`), turns `$1,234.50` / `1.234,50` / ` 12,50 ` into numbers
- **removes blank rows and duplicate orders** (inside one file and across files)
- **logs every change** on an *Issues* sheet (file, row, what happened), so nothing disappears silently
- auto-detects the CSV delimiter (`,` `;` tab `|`)

## Output example

Input: [`samples/`](samples/) - three files generated by `make_samples.py` with all the problems above built in (105 orders, 1 duplicate inside a file, 1 order present in two files, 1 row without quantity, blank rows).

Result: [`output/sales_report.xlsx`](output/sales_report.xlsx) (+ optional [`output/sales_clean.csv`](output/sales_clean.csv))

```
104 clean rows from 3 files, 3 issues logged, revenue 27,990.07 -> output/sales_report.xlsx
```

![Report preview](docs/preview.png)

| Sheet | Content |
|---|---|
| Summary | input files, row counts, date range, total revenue, customers, products |
| Clean Data | one unified table: Order ID, Order Date, Month, Customer, Product, Quantity, Unit Price, Revenue, Source File (filter + frozen header) |
| Pivot | revenue by month x product with row and column totals |
| By Customer | orders, units and revenue per customer |
| Charts | monthly revenue line, stacked revenue by product, revenue by customer - **native Excel charts** (editable, not images) |
| Issues | `south_branch.csv row 9: dropped: missing quantity (order S-1008)`, `webshop_export.xlsx row 32: duplicate of order N-1004 (north_branch.xlsx row 5) - removed`, ... |

The tests check the result against the generated source data: every one of the 104 rows has the right date, customer, product, quantity and price.

## Install and run

Requires Python 3.9+.

```bash
pip install -r requirements.txt
python make_samples.py                     # (re)create the sample input files
python clean.py samples/north_branch.xlsx samples/south_branch.csv samples/webshop_export.xlsx \
       -o output/sales_report.xlsx --csv output/sales_clean.csv
```

On macOS/Linux you can pass a whole folder with a glob: `python clean.py samples/*.xlsx samples/*.csv`.

Run the offline tests:

```bash
python -m unittest -v
```

## Adapting it to your files

1. **`COLUMN_ALIASES`** in `clean.py` - add the column names your files use. Add a new canonical column (e.g. `region`) by adding a key here and to the output headers.
2. **`REQUIRED`** - which columns must be filled for a row to be kept.
3. **Duplicate rule** - `df.duplicated(subset=["order_id"])`; change the subset to e.g. `["customer", "order_date", "product"]` if your data has no unique ID.
4. **Pivot / charts** - `write_report()` builds them with pandas and openpyxl; swap `month x product` for `region x category`, add a sheet per salesperson, etc.

Typical extensions: read every sheet of a workbook, pull files from a shared folder or email attachments, a fixed corporate template, scheduled monthly runs.
